# Prestwick 0.6.0-rc12 (playtest build)

- A fifth famous course, Dogleg Hollow: nine holes that all turn, modelled on famous real doglegs, with a lake, ponds, trees or bunkers in every corner so cutting it is a real gamble, and a double-dogleg par 5. Esc, then Famous courses, to play it.
- Known issues: the economy, sound levels and keyboard-only play have not yet had a person's hand check; the Windows build has not been launch-tested on a machine without Godot.
