# Prestwick 0.9.0

An opening flyover.

- The first time you start the game, a 28-second flyover plays: dawn over Dogleg Hollow (Championship), the camera gliding along the closing holes, a golfer walking to the 18th tee, and a real slice aimed at the trees that bends round the corner in slow motion before the title. It is built from the game's own course, guest and ball. Any key or click skips it; Esc, Watch intro replays it.
- Known issues: the Windows build has not been launch-tested on a machine without Godot.
