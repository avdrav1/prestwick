# Prestwick 0.6.0-rc7 (playtest build)

- Cart paths you can see: with the Cart path tool in hand, every walk your guests make (each green to the next tee, and the clubhouse to the first tee) is drawn on the course, green when a path serves it and red when guests will complain, with the reason ("path stops 19 yd short of the 8th tee").
- Walk complaints name the same reason, and laying or removing a path clears that walk's old complaints so the next guests' verdict shows.
- Paths count from farther away: a path within 40 yd of the green and the tee (was 25) serves the walk, as long as it is quicker than walking across.
- Known issues: the economy, sound levels and keyboard-only play have not yet had a person's hand check; the Windows build has not been launch-tested on a machine without Godot.
