# Prestwick 0.6.0-rc10 (playtest build)

- Better bridges on the example courses. Cliffside gets two new footbridges: across the chasm on the 3rd, from the end of the fairway to the green, and across the inlet where the 5th's slices land, so guests no longer walk a long way round. Old Grey Links' home-burn bridge now reaches both banks.
- If you already have the example courses, delete them from the courses folder (Esc, Import course, Open folder) and restart to get the updated versions.
- Known issues: Cliffside's last group can finish close to dusk on a busy day (queueing on the 1st and 5th tees); the economy, sound levels and keyboard-only play have not yet had a person's hand check; the Windows build has not been launch-tested on a machine without Godot.
