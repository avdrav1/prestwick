# Prestwick 0.6.0-rc11 (playtest build)

- Famous courses are built into the game: Esc, then Famous courses, lists Harbor Links, Old Grey Links, Pine Ridge and Cliffside. Picking one starts a new game on it with $5,000, and every update brings the latest version of each course.
- The copies earlier builds put in your courses folder are tidied away on first start. Any you edited are kept, renamed "... (my copy)".
- A saved game on a famous course keeps the course as you saved it; the menu says when a newer version is available.
- Known issues: the economy, sound levels and keyboard-only play have not yet had a person's hand check; the Windows build has not been launch-tested on a machine without Godot.
