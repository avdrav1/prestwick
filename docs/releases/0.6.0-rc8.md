# Prestwick 0.6.0-rc8 (playtest build)

- Four example courses come with the game, each nine holes modelled on famous real holes: Harbor Links (water and an island green), Old Grey Links (seaside links), Pine Ridge (tree-lined parkland) and Cliffside (clifftops over the sea). Open any of them from Import course in the menu to play it, watch the guests, or rebuild it.
- The course files are attached to this release too, if you want to share them.
- Known issues: the economy, sound levels and keyboard-only play have not yet had a person's hand check; the Windows build has not been launch-tested on a machine without Godot.
